## 한 줄 소개

Python과 FastAPI를 중심으로 API, 데이터베이스, 비동기 작업을 설계하고, AI 기능이 실제 사용자 흐름 안에서 동작하는 제품을 구현합니다.

화면을 만드는 것보다 **어떤 데이터가 어디서 들어와 어떤 경계를 지나고 무엇으로 검증되는지**를 명확하게 만드는 데 관심이 있습니다.

## 내가 일하는 방식

```text
문제 정의  →  데이터·시스템 경계 설계  →  작은 흐름 구현  →  실행 가능한 근거로 검증
```

- **설계:** API, DB, worker, client의 책임을 먼저 나눕니다.
- **구현:** 기능을 한 번에 크게 만들기보다 실제로 흐르는 최소 경로부터 연결합니다.
- **검증:** 테스트, 로그, 설계 문서, 화면 증거를 남겨 “구현했다”에서 끝나지 않게 합니다.
- **공개:** 저장소마다 실행 방법과 제한사항을 함께 적어 재현 가능한 상태를 지향합니다.
